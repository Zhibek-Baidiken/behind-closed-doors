# Behind Closed Doors, Beyond Numbers

Static research website for PLS 419. Open `index.html` to preview locally, or publish with GitHub Pages.

## Publish to GitHub Pages
1. Create a new public GitHub repository (e.g. `behind-closed-doors`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (not a nested folder).
3. Go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
5. After deployment, GitHub shows the public website URL in Pages settings.

## Edit content
- `index.html`: all four sections, research question, sources, and transparency statement.
- `script.js`: regional chart data and filters.
- `style.css`: colors, typography, responsive layout.

## Academic integrity and safety
- Counts in `script.js` were transcribed from the student's uploaded draft; verify against the official statistical workbook before publication.
- The site intentionally does not claim to measure domestic violence prevalence or support-service access from crime counts.
- The research review, two real-world AI case studies, detailed cost estimates, and verified regional service data must be added before the final course presentation.
- This is **not** a support hotline or emergency-response tool. Do not collect sensitive survivor information through a form or chatbot.
